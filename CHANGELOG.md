# Changelog

Notable changes to Smart Piano Fingering are documented here.

## [1.0.0] - 2026-10-12

- Initial repository packaging of the Smart Piano Fingering MuseScore plugin.
- Includes right- and left-hand fingering generation, hand-size presets, optional preservation of existing fingerings, and range-selection filtering.
- Adds repository documentation and GitHub contribution templates.
